This is the respository for the paper titled: Humans infer task difficulty by thinking about human-object interactions

## Repository structure

```
├── code
│   ├── analyses
│   │   ├── e1.Rmd        Experiment 1 (adult build task, difficulty & time estimation)
│   │   ├── e2a.Rmd       Experiment 2a (adult forced choice)
│   │   ├── e2b.Rmd       Experiment 2b (US child forced choice: Lookit; in-person is in som.Rmd)
│   │   ├── e3.Rmd        Experiment 3 (Tsimane' child forced choice)
│   │   ├── e4.Rmd        Experiment 4 (VR)
│   │   ├── figures.Rmd   All figures, main text and SI (sources som.Rmd)
│   │   ├── som.Rmd       All supplementary analyses
│   ├── experiment_code
│   │   ├── e1            jsPsych code for the Exp. 1 pre-registered replication
│   │   ├── e2a           jsPsych code for the Exp. 2a pre-registered replication
│   │   ├── e2b           Children Helping Science (Lookit) study definition for Exp. 2b
├── data                  Analysis-ready data, one file per dataset
│   ├── e1_adult_rep/     Experiment 1 replication, 178 per-subject exports
│   ├── e2_adult_rep/     Experiment 2a replication, 130 per-subject exports
├── figs
│   ├── plots             Figure panels written by figures.Rmd (main text and SI)
│   ├── table             Table S1 (LaTeX), written by som.Rmd
│   ├── paper_figures     Final figures as they appear in the paper (assembled by hand
│   │                     from figs/plots, so these are not regenerated by any script)
├── prereg                Pre-registrations (AsPredicted PDFs)
├── stim
│   ├── exp1
│   ├── exp_2a&3
│   ├── exp_2b
```

## A note on code

```
Every file in code/analyses/ is self-contained: it reads from data/, does its own cleaning
and wrangling in memory, and writes nothing back to data/. There is no separate
cleaning step to run first.

To reproduce a single experiment, open and run that experiment's file
(e1.Rmd, e2a.Rmd, e2b.Rmd, e3.Rmd, e4.Rmd).
```
